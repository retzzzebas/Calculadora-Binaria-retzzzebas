En el caso de abrir cualquiera de los programas en VS Code (recomendable), para compilar el programa, solo basta con que abra algun archivo de extension .java y en la terminal de Visual Studio Code, ejecute el siguiente comando: javac nombreArchivo.java y ponga enter. Y para ejecutar el programa, solo escriba: java nombreArchivo.java seguido de la tecla enter.
Si estas en la terminal de Linux o en el cmd de Windows, solo vaya a la carpeta del repositorio que contiene a todos los archivos, los comandos son los mismos que mencioné arriba.
